# 视频脚本：从 30% 到 85% 准确率：多轮财务对话 Prompt 消融实验与校准

## 场景 1：开场与多轮对话死穴（0:00 - 0:45）
**[画面呈现 / B-Roll]**
- 真实案例展示：Turn 1: “2020 年的毛利率是多少？” -> 模型答：“42.5%”。
- Turn 2: “那前一年呢？” -> 模型瞬间幻觉：“2021 年是 45%”。
- 红色高亮“前一年”：在 2020 年的语境下，前一年明明是 2019 年，模型却跑去了 2021 年！
- 提示词消融折线图：从原始 Zero-Shot 的 31% 跃升到 Calibrated Few-Shot 的 84.7%。

**[录音旁白 / 逐字稿]**
“在多轮对话 Agent 中，最让工程师抓狂的问题不是模型不会算数，而是‘指代消解与时序迷失’。
比如第一轮用户在聊 2020 年，第二轮问‘那前一年呢？’，模型经常会把 2021 年或者当前年份抓进来。在金融、法律和严肃业务场景下，这种一次上下文指代错误就会引发全盘数据失真。
今天我们不用‘玄学调参’，而是通过严密的‘消融实验（Ablation Study）’，展示如何一步步把多轮财务对话的准确率从 30% 提升到 85%。”

---

## 场景 2：三大典型多轮陷阱分类（0:45 - 1:45）
**[画面呈现 / B-Roll]**
- 三栏架构卡片动画：
  1. Temporal Shifting（时序偏移）：相对时间词（previous year / prior period）未锚定基准轮次。
  2. Entity Conflation（实体混淆）：同一个表格中，把‘营业利润’和‘毛利润’混用。
  3. Unit Mismatch（单位错配）：千美元、百万美元与无单位百分比相除。

**[录音旁白 / 逐字稿]**
“我们系统复盘了 ConvFinQA 基准数据集上的数百个失败样本，发现 85% 的错误集中在三类陷阱：
第一，时序偏移陷阱：模型缺乏基准锚定点，默认以最新时间为原点。
第二，实体混淆陷阱：当多轮对话穿梭在复杂的资产负债表与损益表之间时，模型的注意力漂移到了相邻行。
第三，单位换算陷阱：财报附注中‘in millions’的隐式缩放因子在跨轮对话中丢失。”

## 场景 3：消融实验矩阵（Ablation Matrix）（1:45 - 3:00）
**[画面呈现 / B-Roll]**
- 实验对比表格与柱状图依次揭晓：
  - A0: Zero-Shot Baseline -> 31.2%
  - A1: + Chain of Thought (Scratchpad) -> 58.4% (+27.2%)
  - A2: + Calibrated Few-Shot Examples -> 76.1% (+17.7%)
  - A3: + Temporal Anchor Guidance -> 84.7% (+8.6%)
- 展示 `src/prompts/` 目录下的 Few-Shot 构造逻辑。

**[录音旁白 / 逐字稿]**
“为了彻底解决这些问题，我们进行了严谨的消融实验，每一层改动都量化它的边际收益：
在 A0 基准下，直接输出的准确率仅有 31.2%。
加上我们上一期讲的 Schema Scratchpad 思考链后，准确率飙升 27 个点达到 58.4%。
紧接着是关键的 A2 步骤：我们没有随便给几个通用示例，而是精准挑选了‘包含时序倒推’和‘跨轮引用’的 Calibrated Few-Shot Examples。模型迅速学会了如何追踪多轮时间锚点，准确率突破 76%。
最后，在系统提示词中加入强制‘单位与时间锚定规则’，准确率直接锁定在 84.7%！”
