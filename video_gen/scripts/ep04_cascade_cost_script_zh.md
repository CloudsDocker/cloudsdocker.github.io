## 场景 2：级联效应（Error Cascades）的底层解剖（0:50 - 1:45）
**[画面呈现 / B-Roll]**
- 级联推倒多米诺骨牌的 3D 动画。
- 流程图：
  - Turn 1 算错收入基数 -> Turn 2 引用错误基数计算增长率 -> Turn 3 基于错误增长率推导未来估值。
  - 错误随着轮次呈指数级放大，最后彻底产生逻辑死锁。

**[录音旁白 / 逐字稿]**
“这就是著名的‘级联错误（Error Cascading）’。
在多轮 Agent 系统中，状态是具有强时序依赖的马尔可夫链。一旦第一轮抽取的数字出现微小偏差，后续所有轮次都会把错误信息当成真实客观事实进行再推理。
更糟糕的是，很多自愈机制如果设计不当，会触发无休止的重试循环，在短时间内耗尽模型的上下文窗口和组织 API 配额。”

## 场景 3：三大架构防御墙（1:45 - 3:15）
**[画面呈现 / B-Roll]**
- 画面展示三大防御模块的架构图：
  1. Deterministic Multi-tier Cache（多级确定性缓存）
  2. Turn-wise Confidence & Context Pruning（轮次置信度与上下文剪枝）
  3. Spend Cap Circuit Breaker（硬预算熔断断路器）
- 屏幕展示 `src/main.py` 中对应的拦截器代码。

**[录音旁白 / 逐字稿]**
“在企业级生产系统里，我们构建了三道坚不可摧的工程防线：
第一道防线：磁盘与 Prompt 缓存。通过对规范化 Prompt 计算 SHA-256 哈希，建立两级确定性缓存。开发和回归评测时的重复请求全部走缓存命中，将 API 账单立减 60% 以上。
第二道防线：上下文剪枝与状态隔离。绝不把前几轮冗长无用的错误 Token 盲目拼接在上下文中，每轮只传递经过验证的标准化 State 字典，彻底切断幻觉传播链。
第三道防线：严格的预算断路器（Circuit Breaker）。在客户端设置硬性阈值：单次会话 token 消耗上限、单任务重试上限。一旦触碰红线，立即熔断降级并保留 JSONL 现场快照，绝不允许无限烧钱。”

## 场景 4：高可用实战：崩溃安全的 JSONL 持久化（3:15 - 4:15）
**[画面呈现 / B-Roll]**
- 控制台演示：模拟评测中途断电或网络超时中断。
- 重新启动命令，系统秒级检测已有进度并实现 `Resume`（断点续跑），无需从头重跑。
- 展示追加写入（Append-only）的 `results.jsonl` 文件。

**[录音旁白 / 逐字稿]**
“在工业级 FDE 交付中，可靠性（Crash Safety）是基本职业修养。
千万不要把几千条测试数据全存在内存列表里最后一次性写文件！一旦网络抖动或内存溢出，几个小时的评测成果毁于一旦。
我们采用 Append-Only JSONL 格式进行流式持久化，支持毫秒级断点续跑。即使服务器随时被抢占或关机，重启后立即自动跳过已完成项，继续向前推进。”
